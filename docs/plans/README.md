# 计划索引

此目录维护需要跨任务追踪的实施计划、进度和后续事项。
目前没有登记中的实施计划；历史设计方案见 [文档索引](../README.md)。

## 维护方式

- 简单修改无需单独建计划；需要持续追踪时使用 `YYYY-MM-DD-<主题>.md` 命名。
- 每份计划写明目标、范围、状态、实施步骤、验收条件及待解决事项。
- 状态使用「待开始 / 进行中 / 已完成 / 已搁置」，步骤随实际进展更新。
- 创建计划时在本索引添加链接和状态；完成后保留记录，并将长期约定同步到主题文档。
- 计划中的检查项不代表已验证；实际执行结果链接到 `docs/qa/` 的记录。

后续计划在此处登记，不把旧方案中的未来描述自动当作当前待办。
