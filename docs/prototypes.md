# 可交互项目与项目说明

首页仍从 `lib/projects.ts` 经 `lib/reference-home.ts` 派生入口。
已发布项目可额外配置 `prototype: { src, width, height }`；原型能力与发布状态独立。

## 路由与状态

- `/work/[slug]`：配置原型时展示交互体验；未配置时继续使用原有详情模版。
- `/work/[slug]/about`：仅对有原型的项目开放，复用现有 Detail / Showcase 说明。
- 原型页和说明页共用 `app/work/[slug]/layout.tsx` 中的客户端运行容器。
  站内切换时保留 iframe；说明页隐藏原型并移出焦点顺序，返回后继续操作。
  两个视图由共享布局提供，页内切换使用项目专属 History API 导航；
  修改键点击保留原生链接，直接加载两个 URL 均由服务端校验项目。
  这是针对当前 Vinext 生产构建中 Link/RSC 导航错误的局部兼容，未替换全站路由。
- 说明页的返回入口使用客户端导航；其他详情保留原生跨路由导航。
  `ArticleDirectory`、`DetailPage` 和 `ShowcasePage` 的 `clientBackNavigation`
  为此提供可选开关，默认关闭。
- 重新开始重建 iframe，重置原型业务状态；整页刷新、离开项目再进入也会重置。
  同一项目内的浏览器前进/后退保留 iframe；跨项目或重新载入不承诺恢复完整演示状态。
- `/components` 的开发环境限制保持不变。未知、草稿和外链项目不提供原型详情。

运行容器是页面专属实现，位于 `app/work/[slug]/project-experience.tsx`。
原型视图只展示设备画布，不额外显示站点标题、顶部导航或工具栏。
原型与说明的切换、返回首页集中在现有底部 `SiteQuickActions` 悬浮控制台中，
原有语言、AI 输入和主题动作继续保留。操作使用单一水平胶囊工具条，
按「返回｜语言、明暗｜输入｜原型/说明 tabs｜控制器」分组，组间有分割线，
分割线两侧统一留 8px。项目页默认显示工具条，不再提供底部启动按钮；
展开 AI 输入后，Escape 返回常显工具条。
项目视图采用文字 tabs，原型与说明同时可见，当前视图以选中背景突出；
左右方向键可切换。窄屏将项目组移至第二行，场景面板同步上移以避让工具条。
按钮悬浮/键盘聚焦时显示站内 Tooltip。项目页使用 `SiteQuickActions` 的
`project` 参数提供当前视图与切换回调；全站实例在此页面隐藏，避免出现重复控制台。

原型视图中，工具条末尾加入「原型控制台」，点击后在工具条上方居中展开面板，
保留正常、报警、故障场景与重新开始，并显示模拟数据及演示密码说明。
不再提供右下角独立入口。面板打开时工具条保持可见；打开后聚焦场景选择，
Escape 关闭并返回控制台按钮，点击面板外或切换说明页时收起。
说明页隐藏此动作，保留其余五项操作。原型画布预留底部控制空间，说明页仍使用原有排版，
侧栏不重复提供视图切换入口。页面外层使用站点语义 token，设备内部保留产品视觉。

## 第一个接入：仁博智能油雾过滤

- 项目 slug：`renbo-oil-mist`。
- 原型入口：`public/prototypes/renbo-oil-mist/index.html`。
- 原始开发仓库名称：`20261019无锡仁博智能油雾过滤`，仍在原位置独立维护。
- `vendor/` 是只读运行快照，保留原 HTML、CSS、JavaScript、图片与图标许可证。
- `snapshot.json` 记录来源提交、原型目录是否有未提交改动，以及各文件 SHA-256。
- 作品集只导入运行所需文件，不导入原仓库的客户资料、PDF、会议记录或临时截图。
- `portfolio.js` / `portfolio.css` 是接入适配层，原设备业务实现不在作品集中手改。
- 导入脚本生成 `runtime.js`，对嵌入场景作两项适配：移除窗口 focus 尺寸重算监听，
  避免 iframe 获得焦点时取消首个启停点击；resize 和会话校验监听仍保留；缩放计算按实际容器高度适配，避免窄屏短容器被原最小高度裁切。
  若上游监听写法变化，脚本报错要求复核适配。原始 `vendor/app.js` 保持完整。

更新快照时，在作品集根目录执行（路径参数指向原开发仓库）：

```sh
node scripts/import-renbo-prototype.mjs '/path/to/20261019无锡仁博智能油雾过滤'
```

脚本复制 `prototype/` 下的运行文件和资源，生成带适配层的入口及来源清单；
不会更改原开发仓库。更新后检查差异并重新验证，再明确选择需要提交的文件。
生成的原始快照从 Oxlint / Oxfmt 中排除，接入适配层和导入脚本仍执行检查。

## 体验与通信

初始场景为正常运行，清理原演示默认报警；重新开始恢复同一初始状态。
屏幕外提供正常、报警和故障三种场景；原型固定 800 × 480，根据容器等比缩放。
原开发版本的物理尺寸校准、视觉对比和预览控制器在作品集入口隐藏。

父页和适配层使用 `portfolio-prototype` 消息通道，只接受同源且来自预期窗口的消息。
`initialize` / `ready` 完成加载握手，`language` 同步中英文，`scenario` 切换有限场景；
`background` 同步站点语义背景色以消除 iframe 的默认白色画布，设备内部配色不变。
原型内仍可独立切换中英日语言。
网站深浅主题只影响体验容器，保留设备界面自身配色。

访客可以操作启停、报警和参数设置。演示密码为用户 `1234`、厂家 `8888`。
这只是本地模拟，不连接设备或生产服务；参数、权限和设备联锁不代表已完成工程验证。
