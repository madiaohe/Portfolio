## 文档维护

- `AGENTS.md` 保持为简短索引；长期规则和实现细节写入上表对应主题文档。
- 计划放入 `docs/plans/`，验证记录放入 `docs/qa/`，分别维护目录索引。
- 新增或迁移文档时更新本索引及引用链接；仅在新增任务入口时调整 `AGENTS.md`。
- 不重复维护相同规则；相关文档通过链接引用其负责的主题说明。
- 过期说明标注为历史资料，避免旧布局或旧测试结论被当作当前要求。
